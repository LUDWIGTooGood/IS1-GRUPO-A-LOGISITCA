# Normas de Entrega y Control de Calidad (SQA - Documentación)

1. **Rama de trabajo:** Todos los borradores y avances de documentación deben subirse exclusivamente a la rama `dev-documentacion`. Queda prohibido hacer `push` directo a `DOCUMENTACION` o `main`.
2. **Nomenclatura de archivos:** 
   - Plan de Proyecto: `Plan_Proyecto_GrupoA_vX.Y.docx`
   - Especificación de Requisitos (SRS): `SRS_IEEE830_GrupoA_vX.Y.docx`
   - Cronograma: `Cronograma_GrupoA_vX.Y.mpp`
3. **Control de Versiones:** Toda modificación debe quedar registrada en la tabla de historial de cambios al inicio del documento (Versión, Fecha, Autor, Descripción del cambio, Revisor SQA).
4. **Paso a revisión (Pull Request):** Cuando un bloque esté listo para evaluación, se abrirá una Pull Request desde `dev-documentacion` hacia `DOCUMENTACION` asignando como revisor a `@LUDWIGTooGood`.
